# Арт-Детектив — веб-версия

Точный браузерный перенос подтверждённой версии игры на Vite и TypeScript без UI-фреймворка.

## Команды

```powershell
npm install
npm test
npm run build
npm run dev
```

Игра полностью статическая и не требует сервера приложений. Исходные изображения и WAV-файлы скопированы без перекодирования. Сведения об аудиоресурсах находятся в `public/assets/sounds/ASSET_CREDITS.txt`.
