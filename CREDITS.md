## Font

The bundled font is Playfair Display, licensed under the SIL Open Font License 1.1. See [`LICENSES/OFL-1.1.txt`](LICENSES/OFL-1.1.txt).

The file is named `PlayfairDisplay-Bold.ttf`, but its embedded metadata identifies the face as **Playfair Display Regular**, weight **Normal**, version **1.203**. The filename has been retained to avoid changing existing application behavior.
